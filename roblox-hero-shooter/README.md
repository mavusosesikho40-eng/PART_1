# Rift Arena: a hero shooter for Roblox

A team-based hero shooter for Roblox Studio, in the style of games like Marvel Rivals. Pick a hero, use
their abilities and ultimate, combine heroes for team-up bonuses, and fight over a control point
in a best-of-three match. Bots fill the empty slots, so you can play alone or with a few friends.

Every hero, name and the arena are **original**. Marvel's characters belong to Marvel, so they
aren't included. The point of this project is to give you the systems so you can design your
own heroes.

## Play it in two minutes

1. Download [`RiftArena.rbxlx`](RiftArena.rbxlx). On GitHub, open the file and click
   **Download raw file**.
2. In **Roblox Studio**, choose **File → Open from File…** and pick `RiftArena.rbxlx`.
3. Press **Play** (F5). After a 10-second countdown the hero select screen opens. Pick a hero and
   press **LOCK IN**. Bots fill both teams.

- **Test with several players in Studio:** **Test** tab → **Clients and Servers** → choose 2+ players → **Start**.
- **Put it on Roblox:** **File → Publish to Roblox**. R15 avatars are recommended (**Game Settings → Avatar**).

## How a match works

- **Setup (20 s):** everyone picks a hero in their spawn room. The spawn doors stay shut.
- **Battle:** the doors open and the control point unlocks 10 seconds later.
  - Stand on the point with no enemies on it to capture it. More teammates capture faster.
  - While your team holds the point, your score climbs. The first team to 100% wins the round.
  - If both teams are on the point, it is **contested**.
  - In **overtime**, you can't win while an enemy is still on the point.
- **Best of 3 rounds.** Then a new match starts.
- **Respawns** take 6 seconds. You can change hero while dead, or by going back to your spawn room.
- **Your spawn room** heals you. The enemy's spawn room hurts you.
- **Ultimate charge** comes from dealing damage, healing, and slowly over time.
- **Destructible cover:** crates and barricades break when shot and rebuild after a while.

## Where everything lives

```
roblox-hero-shooter/
├── RiftArena.rbxlx              ← the ready-to-open place file
├── default.project.json         ← Rojo project (maps the folders below into Roblox)
├── map/Map.rbxm                 ← the arena, pre-built (generated by tools/bake-map.luau)
├── src/
│   ├── shared/                  → ReplicatedStorage.Shared (server AND client)
│   │   ├── Config.luau          ← match rules, controls, camera, bots, sounds
│   │   ├── Heroes.luau          ← every hero's stats, weapon and ability numbers
│   │   ├── Synergies.luau       ← team-up bonuses
│   │   └── Remotes, CombatUtil, MotionUtil, Signal
│   ├── server/                  → ServerScriptService.Server
│   │   ├── Main.server.luau     ← starts everything
│   │   ├── Services/            ← match loop, combat, weapons, abilities, bots, objective…
│   │   ├── HeroKits/            ← one file of ability code per hero
│   │   └── Map/MapBuilder.luau  ← builds the arena if Workspace.Map is missing
│   └── client/                  → StarterPlayerScripts.Client
│       ├── Main.client.luau
│       └── Controllers/         ← camera, input, HUD, hero select, scoreboard, effects
└── tools/                       ← optional build and check scripts (Rojo + Lune)
```

How the networking works: the server owns the match state and all damage. When you shoot, your
client aims and draws the shot instantly, then tells the server what it hit. The server checks the
claim (fire rate, ammo, range, where the target really is, walls in the way) before it applies any
damage. Projectiles fly on the server, and every client draws them.

## Make it yours

**Tune the game.** Almost every number lives in `src/shared/Config.luau` (match length, bots per
team, respawn time, capture speed, camera, controls) and `src/shared/Heroes.luau` (health, speed,
damage, cooldowns, radii).

**Add a hero.**
1. In `Heroes.luau`, copy an existing entry, give it a new `Id`, and change the numbers and text.
2. Add the `Id` to `Heroes.Order`.
3. Create `src/server/HeroKits/<Id>.luau` with `Kit.Ability1`, `Kit.Ability2` and `Kit.Ultimate`
   functions. Copy the kit closest to what you want. Each function receives `ctx`, which holds the
   character, the hero data, this ability's numbers, and where the player is aiming.
4. Optional: give the hero a look in `Services/HeroVisuals.luau`, and add team-ups in
   `Synergies.luau`.

The existing kits are templates for most ability types:

- dashes: `Bulwark`, `Kaida`
- leaps: `Kestrel`
- teleports: `Volta`
- grenades and other projectiles: `Kestrel`
- placed barriers: `Bulwark`
- damage and healing zones: `Volta`, `Lumen`
- buffs: `Kestrel`, `Lumen`
- team ultimates: `Bulwark`, `Lumen`

**Build your own map.** Edit `Workspace.Map` in Studio, or replace it entirely. The game only
needs these pieces inside `Workspace.Map`:

- `Spawns/Blue` and `Spawns/Red`: folders of parts where heroes appear
- `SpawnRooms/Blue` and `SpawnRooms/Red`: invisible box parts. They heal their own team and hurt enemies.
- `SpawnDoors/Blue` and `SpawnDoors/Red`: folders of parts that block the exits during Setup
- `ControlPoint`: an invisible part in the middle of the objective, with number attributes `Radius` and `Height`
- `PointVisual` (optional): a folder of parts that change to the owning team's colour

To make cover breakable, tag a part `Destructible` (Tags section in Properties) and give it a
`MaxHealth` attribute.

**Sounds, models and animations.** Sounds are built-in Roblox placeholder sounds listed in
`Config.Sounds`. Swap in your own `rbxassetid://` ids. Heroes currently wear simple welded "gear"
parts over the player's avatar. Replace a builder in `HeroVisuals.luau` to weld on your own models.

## Editing the code

- **In Studio:** all scripts are inside the place file (`ServerScriptService.Server`,
  `StarterPlayer.StarterPlayerScripts.Client`, `ReplicatedStorage.Shared`). Edits made this way live
  in your place file, not in `src/`.
- **With Rojo (recommended for VS Code):**
  1. Install [Rojo 7](https://rojo.space) and its Studio plugin.
  2. Run `rojo serve` in this folder.
  3. Click **Connect** in the plugin. Changes you save in `src/` appear in Studio instantly.
  4. If you also edit the map in Studio, remove the `Map` entry from `default.project.json` so
     Rojo doesn't replace your edits with `map/Map.rbxm`.

## Rebuilding and checking (optional)

With [Rojo](https://rojo.space) and [Lune](https://lune-org.github.io/docs) installed:

```bash
lune run tools/check
```

That compiles every file and checks hero, synergy and map data.

```bash
./tools/build.sh
```

That runs the checks, re-bakes the map and rebuilds `RiftArena.rbxlx`.
