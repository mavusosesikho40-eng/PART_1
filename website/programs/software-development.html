Diploma in Software Development

Programming fundamentals through to full-stack web development, with a portfolio project for graduation.

+ Add a photo at images/programs/software-development.jpg
Overview

About this programme

Students start with programming fundamentals and problem-solving, then move through front-end and back-end web development, databases and version control — the same stack used in industry.

The programme is project-based from the second semester onward. Every student graduates with a portfolio of working applications, culminating in an independent capstone project they design, build and present.

What you'll learn

  • Programming fundamentals (logic, data structures)
  • Front-end development (HTML, CSS, JavaScript)
  • Back-end development and databases
  • Version control with Git
  • Software testing and deployment basics

Career outcomes

Graduates take up junior developer, web developer and software support roles, or continue building their own products and freelance work.

  • Junior Developer
  • Web Developer
  • Software Support Technician

Quick Facts

  • Duration 2 Years
  • Study Mode Full-time
  • Qualification NQF Level 6
  • Faculty Information Technology
  • Campus Braamfontein Campus
