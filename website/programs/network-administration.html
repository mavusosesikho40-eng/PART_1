Certificate in Network Administration

Prepares students for industry networking certifications alongside practical lab work.

+ Add a photo at images/programs/network-administration.jpg
Overview

About this programme

This certificate focuses on building, securing and maintaining computer networks, from home office setups to small business infrastructure. Lab time starts in week one, using the same hardware and software used by IT professionals.

Coursework is mapped to industry certification syllabuses, so graduates leave with both a qualification and the preparation needed to sit vendor networking exams.

What you'll learn

  • Network fundamentals and the OSI model
  • Router and switch configuration
  • Network security basics
  • Troubleshooting and diagnostics
  • Preparation for industry certification exams

Career outcomes

Graduates move into junior network administrator, IT technician and network support roles.

  • Junior Network Administrator
  • IT Technician
  • Network Support Technician
