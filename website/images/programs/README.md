# Programme photos

Drop a photo for any programme here and it appears automatically — no code changes needed.

- **Filename**: must match the programme's page exactly, as `<slug>.jpg` (see the list below).
- **Card thumbnail** (academics.html): shown at 16:9. A landscape photo at least 800x450px works well.
- **Detail page banner**: the same file is reused as a wide 21:6 banner at the top of the programme's page. A landscape photo at least 1600x460px looks best; anything landscape will be cropped to fit.
- Until a photo is added, a placeholder (dashed circle + "Add a photo") shows automatically in its place.
