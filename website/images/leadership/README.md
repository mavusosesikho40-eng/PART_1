# Leadership photos

Drop a photo here and it appears automatically — no code changes needed.

- **Filename**: `nomvula-mahlangu.jpg` (the Principal's portrait on `welcome.html`).
- Shown as a 3:4 portrait. A photo at least 900x1200px looks best; anything portrait-oriented will be cropped to fit.
- Until a photo is added, a placeholder (dashed circle + "Add a photo") shows automatically in its place.
